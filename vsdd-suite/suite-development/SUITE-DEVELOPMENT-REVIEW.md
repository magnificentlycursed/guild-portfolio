# VSDD Suite Review Index

The VSDD Suite is itself a software artifact. Like any artifact it has a specification (the VSDD and VDD methodology documents), a design (the domain structure, dimensions, supplement architecture, and session primer set), and an implementation (the domain prompt files, session primers, README, supplements, findings index, and review-log session entries). The adversary should apply to the suite the same pressure it applies to projects under review — to both adversarial review prompts (does this dimension catch a real defect?) and constructive primers (does this primer prevent a real spec or process gap?). The suite has expanded beyond its original VSDD Phase 3 (IAR) scope to own every VSDD phase 1a+1b through 6; see [`../README.md`](../README.md) `## Suite scope` for the artifact map.

This file is the index of suite review sessions. Individual session logs live in `review-log/`, organized as `YYYY-MM-DD-suite-review.md`. A suite review is a single artifact type — sessions vary in mode (defect-search lens vs. registry-walk lens), and the mode lives in each entry's Lens field rather than in a separate artifact type. See [`suite-development.md`](suite-development.md) for the entry format.

**Three audiences ([Review 80](review-log/2026-05-20-suite-review.md#review-80--2026-05-20-1830z) Finding 3; renamed in [Review 84](review-log/2026-05-21-suite-review.md#review-84--2026-05-21-1100z) Finding 4):** this index — like its companion [`FINDINGS-INDEX.md`](FINDINGS-INDEX.md) — is authored for (1) **suite developers** (contributors extending the suite — read the Reviews table to understand the methodology's history + the open backlog); (2) **suite users** (project teams applying VSDD — model what their own project-level review-index should look like); (3) **AI agents** (Lens-field grep + Review-anchor direct-link + per-Finding anchor IDs from Review 80 forward). The Reviews-table column shape + the per-row Lens vocabulary are stable agent-API surface; the full Agent-API contract is in [`suite-development.md`](suite-development.md) [§ Agent-API surface](suite-development.md#agent-api-surface-review-80-finding-3). See [`suite-development.md`](suite-development.md) [§ Three-audience design principle](suite-development.md#three-audience-design-principle-review-80-finding-3) for the full discipline.
