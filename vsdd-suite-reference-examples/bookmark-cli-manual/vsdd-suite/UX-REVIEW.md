**Reviewer role: UX Designer** (UX Designer / UX Researcher / Product Designer)

Evaluates the lived user experience: interaction flows, error states, output quality, the experience the user actually has.

**Activation:** Core domain — always active at capstone intent.

**Language supplement applied:** `../../../vsdd-suite/supplements/cli.md` § UX (CLI projects).

**Sycophancy check:** An AI agent cannot experience a user interface. An agent reviewing its own UI implementation will validate the decisions it made at generation time rather than evaluate the lived experience those decisions create.
